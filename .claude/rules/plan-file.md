## 要約版にもサンプルを載せる

**何かを書くと書いたら、パスと中身のサンプルを添える。要約版にもサンプルを載せる。**サンプルが無いと人間がレビューできない。

## 範囲リンクの開始行

**範囲リンク（`#L12-L34`）の開始行が表のヘッダや空行になるのは、正しいことがある。**
表の全体を指すときは、ヘッダ行から始めてよい。リンクを検算して「空行」「区切り行」と出ても、表の全体を指しているならずれではない。
