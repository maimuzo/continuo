# worker への指示の書き方

**worker とは、Workflow の agent と subagent のことである。**

## 絶対条件：worker にも、判断の土台を読ませる

**指示だけを渡してはならない。**

**worker は、このリポジトリの制約を何も知らない状態で立ち上がる。**
**CLAUDE.md も [.claude/rules/](.claude/rules/) の下のファイルも、自動では読まれない。**

**実例。**2026-09-01、6本の PR のマージを worker に任せた。
**指示には手順だけを書き、CLAUDE.md を読ませなかった。**
**worker は渡された確認コマンドをそのまま使い、2本をレビュー未実施のままマージした。**

ユーザー指摘: **「worker側も、なんでルール読んでで作業しないんだ。
なんでworker側にもルールを読ませて、作業に至った過程を説明しないんだ?
それをしないから、判断ミスが起きるんだろうが。根本的に指示の仕方を変えろ」**

---

## 指示に必ず入れる4つ

| 順 | 何を | なぜ |
| --- | --- | --- |
| **1** | **読ませる文書の一覧**（絶対パスと、何が書いてあるか） | 読まなければ守れない |
| **2** | **なぜこの作業が要るのか**（依頼の原文つき） | 目的が分かれば、指示の穴を worker が埋められる |
| **3** | **読んだうえで答えさせる問い**（下に例） | 読んだふりを防ぐ |
| **4** | **根拠の付け方と、言葉づかい** | 検査できない報告は受け取れない |

---

## 1. 読ませる文書の一覧

**絶対パスで書く。**worker の作業ディレクトリは、こちらと違うことがある。

```markdown
## 作業を始める前に、必ずこれを読んでください

| ファイル | 何が書いてあるか |
| --- | --- |
| `<リポジトリ>/CLAUDE.md` | **絶対に守る制約。**とくに（この作業に効くものを名指しする） |
| `<リポジトリ>/.claude/rules/<関係するもの>.md` | （何が書いてあるか） |
```

**「関係するもの」を選ぶのはメインエージェントの仕事である。**
**全部読ませると、読まれない。**

---

## 2. なぜこの作業が要るのか

**依頼の原文を引く。**要約しない。

**目的が分かっていれば、指示に穴があっても worker が気づける。**
**手順だけを渡すと、穴に落ちたことにも気づかない。**

---

## 3. 読んだうえで答えさせる問い

**作業に入る前に、次を自分で答えさせる。**

```markdown
**読んだうえで、次に自分で答えてから作業に入ってください。**

1. **この作業は、上のどの規則に当てはまりますか**
2. **飛ばしてよい段はありますか。あるなら、どの文書のどの記述が飛ばしてよいと言っていますか**
3. **公開してよくない情報を、成果物に書きうる場面はありますか**

**答えを、最初の報告に書いてください。**
```

**3つ目は、公開リポジトリで作業するときに必ず入れる。**

**問いは作業の種類によって変える。**上の3つは最低限である。

---

## 4. 根拠の付け方と、言葉づかい

**この塊は、どの worker への指示にも入れる。**

```markdown
## 根拠の付け方

- 主張1つにつき、ファイル名と行番号、コード片（原文のまま）を添える
- 実行して確かめたことは、コマンドとその出力（原文のまま）を添える
- **「無い」ことの主張には、検索パターン・対象パス・対象コミットの3点を添える**
- **「〜のはず」「たぶん」で終わらせない**

## 言葉づかい

- **issue と PR は必ず「#NNN（内容）」の形で書く**
- **英語の技術用語（worktree / branch / commit / hook）は英語のまま書く**
- **文書やファイルの種類を抽象名詞で指さない。**パスで書く
```

---

## 検査するコマンドを渡すときは、自分で試してから渡す

**メインエージェントが書いたコマンドの誤りは、worker には見抜けない。**

**実例。**「レビュー結果が貼ってあるか」を確かめるコマンドに `contains` を使った。
**本文の途中に同じ文字列があるコメントを、1件と数えた。**

```
# 誤り
--jq '[.comments[] | select(.body | contains("<目印>"))] | length'

# 正しい
--jq '[.[] | select(.body | startswith("<目印>"))] | length'
```

**渡す前に、期待した答えが返るかを自分で1回叩く。**
**通ってはいけないものが通らないことも確かめる。**

---

## 不可逆な操作は worker に渡さない

| 何 | 誰がやるか |
| --- | --- |
| **PR のマージ** | **メインエージェント**（[CLAUDE.md](../../CLAUDE.md) の「PR のマージは、メインエージェントが自分で行う」） |
| ファイルやディレクトリの削除 | メインエージェント |
| 本番のボードへの書き込み | メインエージェント |
| release の作成 | メインエージェント |

**worker には、調べること・書くこと・レビューすることを渡す。**
