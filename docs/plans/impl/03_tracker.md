## 実装の記録

**実装済み**（2026-08-18〜19）。`internal/tracker` に adapter / auth / graphql / query / tracker / errors。

**実装から見つかった注意点。**

- **複数の Status を OR で絞るときはカンマ区切り。**空白区切りは AND になり、**無言で0件を返す**
- **`updateProjectV2Field` を絶対に呼ばない。**選択肢の指定が全件置き換えとして扱われ、
  **設定済みの Status が全部消える**（本番のボードに104件のデータがある）
- **枠を使い切ると HTTP 200 のままエラーメッセージが返る。**応答の `errors` を必ず見る
- **巡回のクエリはネストが4本あるので 1リクエスト 4 point。**毎時 480 point になる（3-31）
