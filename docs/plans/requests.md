## 見落としを機械で止める仕組み

**返答にコマンドを書いたのに、その turn で1度も実行していなければ止める。**

| 何 | どこ |
| --- | --- |
| 検査 | [.claude/hooks/check-verified-commands.py](../../.claude/hooks/check-verified-commands.py) |
| 登録 | [.claude/settings.json](../../.claude/settings.json) の `hooks.Stop` |

**なぜ要るか。**この道具を作った本人が、自分で作ったサブコマンドのフラグの位置を間違えて人間に見せた。
実装を知っていたのに、**書くときに参照しなかった。**原因は「コードとテストは実行して確かめるのに、
返答に書くコマンドは実行しない」という扱いの差である。**その区別に根拠は無い。**

**逃げ道。**実行できないもの（本番へ書き込む・枠を消費する・利用者の環境でしか動かない）は、
コマンドの近くに「未実行」と書けば通る。**書けば通るが、書かずに通ることはできない。**

**動くことを確かめてある。**

| 場合 | 結果 |
| --- | --- |
| コマンドを書いたが実行していない | **止まる** |
| コマンドを書き、その turn で Bash を呼んでいる | 通る |
| コマンドを書き、「未実行」と断ってある | 通る |
