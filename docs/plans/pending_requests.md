## 0-0b. worker の worktree は main から切られない（2026-08-29 に実測）

**言いたいこと。**workflow の `isolation: "worktree"` は、セッション開始時の commit から切る。
**main が進んでいても追随しない。**だから worker は、直前に決めた設計を読めないまま実装する。

**実測。**12件の worktree が全部 `923a368` から切られた。main の HEAD は `ecd4144` で、間に 15 commit ある。
その 15 commit に、issue #60（公開 issue のコメントから実行させられる経路）の3つの守りの設計が入っていた。
**3人の worker のどれも、実装すべき設計を1文字も読んでいなかった。**

**採る対策。**worker への指示の冒頭に、次を必ず入れる。

```bash
cd <worktree>
git merge main --no-edit
```

**競合したら docs/plans/continuo_design.md は main 側を採る、も併せて書く。**
