# プランファイルのレビュー（2周目）の対応表

**対象。**1周目の対応表（[08_plan_review_round1.md](08_plan_review_round1.md)）で書き直した版。**1周目の版からの `diff -u` と1周目の対応表だけを渡した**（計画の9節の形）。
**確かめ役。**general-purpose（Bash あり。読むだけ）。重さは計画ファイルの10節の基準で付けさせた。
**結果。**Critical 0件・High 5件・Medium 10件・Low 6件。1周目で「直す」とした28件のうち26件は理由どおりに直っていた。2件は直し方が理由と食い違っていた（下の表に含む）。「直さない」とした2件は、理由がいまも成り立つと判定された。

**High 5件の内訳。**1周目の版から在ったもの（1周目のレビューが見落とした）3件、1周目の直しが持ち込んだもの2件。
