## 端末が要る経路

**擬似端末（pty）を用意しないと再現できない経路がある。**`ask` は `/dev/tty` から読むため、標準入力を差し替えても通らない。

| 経路 | 何が要るか |
| --- | --- |
| 基本フロー 8〜13（尋ねて、利用者が承諾して、入れる） | 端末と、承諾の入力 |
| 代替フロー `導入を断る` | 端末と、断る入力 |
| 代替フロー `導入の失敗` のうち、尋ねてから失敗する経路 | 端末と、承諾の入力 |

**この経路を書くために `github.com/creack/pty` を足すことはしない**（2026-08-21 の判断。変えていない）。**人間が1度手で確かめる。**
`--yes` を使う経路（任意時点代替フロー `確認を省く指定`）は、端末が無くても通せる。テストは `test/install/前提の道具を調べて入れる_test.go` に在る（判断 17）。
