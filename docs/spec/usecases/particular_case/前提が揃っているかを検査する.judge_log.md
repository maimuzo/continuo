## 4本の枝を足すかどうかの判定

**バックアップに在って本流に無かった4本は、すべて実装に対応する分岐が在ったので足した。**
**足さないと判定したものは1本も無い。**判定の根拠は上の表の 33〜36 にある。

| 枝 | 判定 | 対応する実装 |
| --- | --- | --- |
| 引数の指定が不正 | 足す | `internal/cli/cli.go` の `runDoctor` の位置引数の検査 |
| 確かめる対象が0件 | 足す | `internal/doctor/checks.go` の `checkClone` / `checkTrust` の `len(repos) == 0` |
| 検査結果を書き出せない | 足す | `internal/cli/cli.go` の `runDoctor` の `report.Write` の失敗 |
| 確かめられなかった見出し語がある | 足す | `internal/doctor/report.go` の `Write` の要約の3分岐 |

## 1周として書き直したときに RUCM から落としたもの

**落としたのは「どの見出し語か」に依存する分岐だけである。**次の3つは RUCM の本文から消えたが、
**`.rucm.md` の表と実装のコメントに残してある。**

| 落としたもの | いまどこにあるか |
| --- | --- |
| 見出し語ごとに何を確かめるか（11件） | `.rucm.md` の「見出し語ごとに何を確かめるか」の表 |
