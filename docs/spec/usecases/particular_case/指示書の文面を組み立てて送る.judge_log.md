# 判断ログ: 指示書の文面を組み立てて送る

- 対象: `docs/spec/usecases/particular_case/指示書の文面を組み立てて送る.rucm.md`
- 作成日 / 作成モデル: 2026-10-02 / Claude Opus 5.5
- 参照した根拠資料: `internal/prompt/prompt.go`、`internal/orchestrator/prompt.go`、`internal/orchestrator/turn.go`、`internal/orchestrator/relay.go`、`internal/orchestrator/lifecycle.go`

## この記述を作った経緯

`指示書に沿って issue を1件仕上げる` の経路が掛け算で増えたので、人間の決定（経路が掛け算で増える記述は分ける）に従って、システムの段だけをここへ分けた（issue #110）。
