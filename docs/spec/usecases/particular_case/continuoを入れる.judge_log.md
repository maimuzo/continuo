## 安全性のレビューを受けて変えたこと

**2026-08-21 のレビューで、実際に起こせる欠陥が見つかった。**そのとき RUCM へ入れたものと、いまどこに当たるかを並べる。

| 何が起きていたか | いまどこに書いてあるか |
| --- | --- |
| **取得先を環境変数で丸ごと差し替えられた** | 取得先はフラグでしか変えられない。変えた実行は注意が出て、基本フロー 2 の確認を通る |
| **`--version` に `../` を入れると別のリポジトリの release へ届いた** | 任意時点代替フロー `使えない版の指定`。**配布サーバへ1度も繋がずに止まる** |
| **`checksums.txt` に対象の行が無くても「照合しました」と表示していた** | `配布物を取って置く` の代替フロー `照合できずに止まる`。既定では止まる |

## 端末が要る経路

**擬似端末（pty）を用意しないと再現できない経路がある。**`ask` は `/dev/tty` から読むため、標準入力を差し替えても通らない。
この記述では、代替フロー `取得先の確認での中止` が当たる。`前提の道具を調べて入れる` の側の経路は、そちらの判断ログに書いた。
**この経路を書くために `github.com/creack/pty` を足すことはしない**（2026-08-21 の判断。変えていない）。**人間が1度手で確かめる。**
