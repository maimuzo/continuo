# ユースケース: 設定ファイルを作る

## 根拠資料

- `docs/plans/continuo_design.md` の「3-32. 使い始めるまでの手順」（`continuo init` は利用者に手で埋めさせない）
- `docs/plans/continuo_design.md` の「5-1. ファイルの名前と探し方」
- `docs/plans/continuo_design.md` の「5-3o. `continuo init` が置く2枚目（`continuo-ci.yaml`）」
- `docs/plans/continuo_design.md` の「3-59. ファイルの書き換えは一時ファイルへ書いてから差し替える」
- `docs/trying_it_out.md` の「段3. 設定を置く」（実際に叩いた出力）
- `internal/cli/cli.go` の `runInit` / `printInitCI` / `printDetection` / `parseErrorExitCode`
- `internal/scaffold/init.go` の `WriteAll` / `WriteCIWorkflowWithValues` / `InitResult` の `BothExisted` / `Wrote`
- `internal/scaffold/scaffold.go` の `WriteTemplateWithValues` / `writeOne` / `resolveTarget` / `openError`
- `internal/scaffold/fill.go` の `TemplateWithValues`
- `internal/scaffold/template.go` の `workflowTemplate`

値を決める段（owner・ボードの番号・リポジトリ）は、`設定に書く値を gh から引く.rucm.md` に書いてある。

2. ABORT

SPECIFIC ALTERNATIVE FLOW 引数指定エラー:

2. システムは利用者にディレクトリを先に作る案内を応答する。
3. ABORT

13. システムは利用者に continuo-ci.yaml の絶対パスを応答する。
14. システムは利用者に continuo-ci.yaml を CI へ移す案内を応答する。
15. RESUME STEP 19
POSTCONDITION: WORKFLOW.md の内容が雛形の全文に置き換わっている。continuo-ci.yaml の内容が見本の全文である。終了コード 0 が返っている。

SPECIFIC ALTERNATIVE FLOW 設定ファイルを差し替えられない:

2. ABORT

2. システムは利用者に continuo-ci.yaml を書けなかった理由を応答する。
3. システムは利用者にキーごとの値の決め方を応答する。

2. システムは VALIDATES THAT 書き出す先の continuo-ci.yaml を書き出せる。

GLOBAL ALTERNATIVE FLOW 書き込み中の中断:
BRANCH FROM BASIC FLOW 11
WHEN 利用者が continuo init の実行を中断する場合
1. システムは雛形の全文の書き込みの途中で終了する。
